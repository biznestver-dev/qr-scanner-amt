# Настройка приложения

## Google Apps Script

1. В настройках проекта Apps Script добавьте Script Property `BOT_SHARED_SECRET` — длинную случайную строку для запросов Telegram-бота.
2. Опубликуйте Web App с настройками:
   - **Execute as:** Me.
   - **Who has access:** Anyone.
3. После изменения `GoogleScript.gs` создайте новую версию и обновите deployment.
4. Один раз запустите в редакторе Apps Script функцию `createDailyOverdueTrigger`, чтобы удалить старый автоматический триггер. Новые автоматические триггеры больше не создаются.

## Telegram-бот

Добавьте тот же `BOT_SHARED_SECRET` в `.env` рядом с `BOT_TOKEN`:

```env
BOT_SHARED_SECRET=replace-with-a-long-random-value
```

После этого перезапустите бота. Команда `/start` регистрирует или обновляет чат в листе `Пользователи`; повторные запуски не создают дубликаты. Бот не обрабатывает инвентарные номера, QR-коды, справочники или команды управления.

Автоматическая рассылка отключена. Напоминание можно отправить вручную кнопкой «Должники».

Не добавляйте `.env` в Git и отзовите ранее раскрытый `BOT_TOKEN` через BotFather.

Вход и роли веб-приложения отключены. Его интерфейс и API доступны без авторизации. URL Apps Script встроен в клиентское приложение, поэтому любой посетитель сможет его обнаружить, читать базу оборудования и вызывные листы, а также изменять статусы, акты и другие данные. Используйте этот режим только если такой доступ допустим.
